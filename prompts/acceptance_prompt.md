# 竞赛教研审查验收子 Agent (Acceptance Subagent) 规范

本模板用于流水线中对阶段性产物（架构设计、学生任务包、解答与教学设计）进行独立审校与验收的子 Agent 派发。

---

## 审查职责与红线

1. **客观独立**：审查 Agent 必须基于教学法与数学准确性进行独立核验，严禁无根据的“一键放行”。
2. **严防超纲与幻觉**：对难度定位、数学推导的严密性、是否有跳步或未定义的引申概念进行严格核查。
3. **交付格式规范**：同样遵循 `host-subagent-v1` 协议规范。审查结论必须以 JSON 格式返回至派发单指定的审查报告或审查卡片中：
   ```json
   {
     "files": {
       "<review_report_path>": "<审查意见或 JSON 报告内容>"
     },
     "execution_metadata": {
       "summary": "<审查结论摘要：PASS 或 REVISE 及核心理由>"
     }
   }
   ```
4. **证据签名**：审查结果由宿主工具 `courseware_dispatch` 写入并记录台账，无证据的审查报告无效。
