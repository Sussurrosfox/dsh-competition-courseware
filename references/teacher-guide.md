# 教师端课堂操作说明（竞赛精研学案，v2）

本 skill 把已冻结的教研交接包转化为"少题深研"研讨课材料。教师端不改写
题目，而是控制揭示节奏、组织研讨、记录证据。规则以 `SKILL.md`、
`references/workflow.md` 与 `references/reveal-levels.md` 为准；字段与
枚举以 `../schemas/` 为准。

## 材料清单（发放载体）

| 材料 | 文件 | 用途 | 发放时机 |
|---|---|---|---|
| 学生学案（首轮） | `release/student.pdf` | 题面、任务、独立作答留白、前置知识 | 课初（initial） |
| 教师资料 | `release/teacher.pdf` | 完整证明、教学要点、提示与复盘内容 | 仅教师持有 |
| 提示页 | `release/release-later/hint-<pid>.pdf` | 某题卡住后的 L1 方向提示 | 课堂事件触发（如 `attempt-<pid>-finished`） |
| 复盘页 | `release/release-later/review-<pid>.pdf` | 经审定的结论与方法回顾 | 任务完成/复盘环节 |
| 课堂计划 | `teaching/classroom-plan.md` | 全课时间、发放顺序（事件 → 块）、教师动作 | 课前备课 |
| 内容清单 | `teaching/materials.json` | 全部信息块及可见性（level/available_after/audience/channel） | 备课核对 |

**关键机制**：静态 PDF 不会因为把提示印在留白之后就延迟揭示。提示页与
复盘页是**独立 PDF**，只在对应课堂事件发生后才发给学生；教师资料任何
时候不得发给学生。课初发下去的 student.pdf 里**没有**提示与解答——
不要在现场用教师资料投影补救"发错版本"。

## 课前准备

1. 通读 `teaching/classroom-plan.md`：全课时间、关键任务、每个课堂事件
   对应发放哪些块（事件 → delivery_channel → 载体）；
2. 通读 teacher.pdf 的证明与教学要点，独立重算关键步骤与等号条件；
3. 标出每题的 L0/L1/L2 边界：哪些话学生尝试前可说（L0），哪些只在
   事件触发后说（L1，与提示页一致），哪些只留在教师侧（L2）；
4. 打印分阶段材料：student.pdf 按人数；hint-\<pid\>.pdf / review-\<pid\>.pdf
   按需少量备用，课前不收进学生资料袋；
5. 发布前确认构建与检查记录有效：build.py 逐视图通过、
   compare_versions.py 学生侧 PDF 无禁用标记、check_teaching.py 通过；
   脚本全绿不等于语义合规——以学生视角翻一遍 student.pdf 实际渲染页，
   确认题目、留白、提示阅读顺序正常、同页没有提前暴露关键提示。

## 课中原则

- **先独立，后揭示**。独立尝试时间内不给提示；出现课堂计划约定的触发
  事件（普遍卡点或到时）才发放对应提示页（L1 方向），L2 始终留在
  教师侧或复盘环节。
- **探究由学生承担**。教师不复读结论、不扮演教练、不代学生完成探索。
- **错误路线当诊断材料用**。先让学生指出"哪一个观察使原路线失效"，
  再展示完整失败链；学生版通常只有起点和一个受阻处，完整链在教师版。
- **复盘先问信号**。顺序：失败证据 → 触发信号（什么条件提示用这个
  方法）→ 适用边界 → 迁移。复盘页在复盘环节发放；teacherNote 只供
  教师决策，不朗读。
- **无提示页需求的题照常使用**。materials 中没有该题 separate_hint 块
  时不会生成对应入口——这是纯独立题，不补口头"编剧式"提示。
- **时间不足时**：压缩复盘展示，不压缩独立尝试。

## 卡点处理

- 答案正确：追问触发信号与替代路线，核对判据；
- 路线分歧：先同伴比较失败证据，再由教师展示诊断；
- 大面积空白：达到课堂计划的提示触发条件后发提示页，学生继续；
  不要直接口述 L2；
- 发现材料本身有数学错误（题面/证明/等号/提示计划违反目标）：
  不现场改写材料，课后提交 RESEARCH_BACK issue（见 workflow.md）。

## 课后闭环

- **只有真实试教后才记录课堂数据**：卡点分类、实际用时、学生证据
  拍照/收集情况，记入课后真实反馈记录（templates/error-log.md 或
  项目约定的反馈文件）。模型模拟的预测数据**单独保存**并明确标注为
  预测，不得写成"学生已掌握"的事实，不与真实试教数据混放。
- 反馈按性质分流：选题/数学/模式问题 → 回教研（RESEARCH_BACK）；
  措辞/版面问题 → 教学局部修订（TEACHING_FIX / LAYOUT_FIX）。
- 每次修订只改一个变量（揭示层级、独立时间或迁移题），
  重新运行检查脚本并保留版本记录。
